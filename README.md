# FraudBench-Hybrid-Framework

## A Reproducible Hybrid Framework for Temporal Bank Fraud Detection

FraudBench-Hybrid is a reproducible research framework for temporal bank fraud detection. The framework focuses on leakage-controlled machine learning, temporal data separation, heterogeneous model stacking, out-of-fold prediction, validation-only threshold selection, reproducible evaluation, and preservation of final research artifacts.

The final model developed in this framework is a:

**Leakage-Controlled Heterogeneous Stacking Ensemble**

---

## 1. Project Overview

The primary objective of this project is to develop a leakage-controlled and temporally robust machine-learning framework for detecting potentially fraudulent banking transactions.

The proposed hybrid framework combines predictions from multiple heterogeneous machine-learning models through a LightGBM meta-learner.

The experimental pipeline incorporates:

- Temporal data separation
- Feature-level leakage auditing
- Heterogeneous base learners
- 5-fold Out-of-Fold (OOF) stacking
- LightGBM meta-learning
- Validation-only threshold selection
- Untouched temporal test evaluation
- Final reproducibility verification
- Preservation of model and prediction artifacts

The final model is the **Leakage-Controlled Heterogeneous Stacking Ensemble** implemented within this hybrid framework.

## 3. Final Model Architecture

### Final Model

**Leakage-Controlled Heterogeneous Stacking Ensemble**

### Base Learners

The ensemble consists of six heterogeneous base learners:

1. LightGBM
2. XGBoost
3. ExtraTrees
4. CatBoost
5. Linear SVM
6. MLPs

### Meta-Learner

**LightGBM**

The predictions generated by the heterogeneous base learners are combined through a LightGBM meta-learner using out-of-fold training predictions.

### Stacking Strategy

**5-fold Out-of-Fold (OOF) stacking**

### Final Operating Threshold

**0.72**

The operating threshold was selected using validation data and subsequently locked before evaluation on the untouched temporal test set.

## 5. Temporal Data Split

A total of 1,000,000 transaction observations were divided into three temporally ordered subsets:

| Dataset | Samples |
|---|---:|
| Training | 700,000 |
| Validation | 150,000 |
| Temporal Test | 150,000 |
| **Total** | **1,000,000** |

The temporal ordering of the train, validation, and test sets was verified during the final reproducibility check.

The validation and temporal test sets were not used for model training.

---

## 6. Leakage Control

The following variables were excluded from the final model input:

- `fraud_type`
- `transaction_id`
- `customer_id`
- `transaction_date`
- `transaction_time`
- `is_fraud`

In particular, `fraud_type` was excluded because it is target-derived and therefore unsuitable as a predictive model input.

The final reproducibility verification confirmed that these variables were excluded from the final feature set.

---

## 7. Out-of-Fold Stacking

A 5-fold Out-of-Fold prediction strategy was used for stacking.

Each base learner generated out-of-fold predictions for the training observations. These OOF predictions were subsequently used to train the LightGBM meta-learner.

The validation and temporal test sets were kept outside the OOF training procedure.

The final reproducibility stage verified the OOF-based stacking configuration.

---

## 8. Threshold Selection

The final operating threshold was:

**0.72**

The threshold was determined using validation data only.

After selection, the threshold was locked and applied to the untouched temporal test set.

No test-set threshold search or test-set threshold optimization was performed.
